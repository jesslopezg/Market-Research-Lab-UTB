# Market Research Lab | UTB

Aplicación de investigación de mercados desarrollada con React y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

Desplegar en Vercel con el framework Vite y el directorio de salida `dist`.

Los proyectos se guardan en el almacenamiento local del navegador y pueden exportarse a JSON.
